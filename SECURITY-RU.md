# Безопасность

[English](SECURITY.md) | Русский

Токен передаётся через окружение. Храните его в локальной конфигурации с ограниченным доступом или хранилище секретов. Не включайте токены, приватные выгрузки и реальные ответы API в коммиты, issue, pull request и логи.

MCP передаёт в клиент данные задач и страниц, а также содержимое запрошенных вложений: выбирайте клиент и модель, которым разрешено обрабатывать эти данные. Сервер скачивает выбранные вложения в память и возвращает их как текст, изображения или исходные бинарные ресурсы без создания локальных выгрузок. Файловые CLI сохраняют вложения на диск.

Перед отправкой изменений проверяйте `git diff --cached` и `git status --short`. `.gitignore` защищает только перечисленные пути: экспорт, созданный вне `exports/`, требует отдельной проверки.

Если обнаружена уязвимость, используйте приватное сообщение об уязвимости во вкладке Security репозитория GitHub, если владелец включил эту возможность. Если приватный канал отсутствует, создайте issue только с просьбой предоставить безопасный канал связи, без деталей эксплуатации, секретов и пользовательских данных. Отдельный адрес безопасности пока не опубликован.
